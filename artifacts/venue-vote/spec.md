## 개요

회식 장소 추천 결과에서 주최자가 후보를 골라 투표를 만들고 참석자에게 링크를 보내면, 참석자는 로그인 없이 링크로 들어와 제한시간 안에 원하는 곳(복수 선택 가능)에 투표한다. 제한시간 안에는 같은 링크로 다시 들어와 선택을 바꿀 수 있다. 득표수는 실시간으로 공개되고, 제한시간이 지나면 더 이상 투표(변경 포함)할 수 없고 최종 결과만 남는다.

## 범위

### 포함
- 추천 결과 화면에서 5곳 중 일부를 골라 투표 만들기 (제한시간 선택: 30분/1시간/3시간/내일까지)
- 투표 생성 시 참석자에게 보낼 수 있는 공유 가능한 링크 발급 (카톡 등으로 공유)
- 링크로 들어온 참석자는 로그인 없이 후보 중 여러 곳을 선택해 투표
- 같은 기기(브라우저)는 하나의 투표로 취급되며(기기 기준 best-effort 식별, 완전한 부정 투표 방지는 아님), 제한시간 안에는 같은 링크로 다시 들어와 선택을 바꾸고 다시 제출할 수 있다
- 투표 진행 중에도 각 후보의 실시간 득표수 공개
- 제한시간 경과 시 투표 버튼 비활성화, 최종 득표수만 열람 가능
- 결과 화면에서 "진행 중인 투표" 목록으로 주최자가 만든 투표들을 다시 확인

### 제외
- 참석자 신원 확인(로그인, 실명 인증) — 링크만으로 접근하는 익명 투표다. 완전한 중복 투표 방지는 이번 범위에 포함하지 않는다.
- 투표 종료 시 1위 장소 자동 저장 — 저장은 여전히 추천 결과 화면의 저장 기능을 통해서만 이루어진다.
- 투표 취소/조기 마감, 후보 수정 — 한 번 만든 투표의 후보·제한시간은 바꿀 수 없다.
- 완료(마감)된 투표 목록의 별도 보관함 — "진행 중인 투표" 목록에 마감된 투표도 함께 보이되(상태만 다르게 표시), 그 이상의 히스토리 관리 기능은 다루지 않는다.

## 시나리오

### 1. 투표 만들기
- **Given** 추천 결과 화면에 카드 5개가 표시되어 있다
- **When** 그중 3곳을 체크하고 "투표 만들기" 버튼을 클릭한 뒤 제한시간으로 "1시간"을 선택해 확정한다
- **Then** 체크한 3곳을 후보로 하는 투표가 만들어지고, 참석자에게 보낼 수 있는 공유 링크가 표시된다

성공 기준:
- [ ] 카드 3개 체크 → "투표 만들기" → 제한시간 "1시간" 선택 → 확정 → 공유 링크(URL)가 화면에 표시된다
- [ ] 결과 화면의 "진행 중인 투표" 목록에 방금 만든 투표가 나타난다

### 2. 후보 없이 투표 만들기 시도
- **Given** 추천 결과 화면에서 체크된 카드가 없다
- **When** "투표 만들기" 버튼을 클릭한다
- **Then** 투표가 만들어지지 않고, 최소 1곳을 선택해야 한다는 안내가 표시된다

성공 기준:
- [ ] 선택 없이 투표 만들기 시도 → "투표할 장소를 선택해주세요" 안내가 나타나고 새 투표가 생성되지 않는다

### 3. 참석자가 링크로 투표 참여
- **Given** 주최자가 후보 3곳으로 제한시간 1시간짜리 투표를 만들어 링크를 공유했다
- **When** 참석자가 그 링크로 접속해 후보 중 2곳을 체크하고 "투표하기" 버튼을 클릭한다
- **Then** 투표가 제출되고, 화면에는 각 후보의 실시간 득표수가 갱신되어 표시된다

성공 기준:
- [ ] 후보 2곳 체크 후 투표하기 클릭 → 그 2곳의 득표수가 각각 1씩 증가해 화면에 표시된다
- [ ] 투표 제출 후 "투표하기" 버튼이 비활성화되거나 "투표 완료" 안내로 바뀐다

### 4. 같은 기기에서 투표 변경
- **Given** 이 기기(브라우저)로 후보 A, B에 투표를 제출한 상태이고 아직 제한시간이 남아 있다
- **When** 같은 투표 링크를 다시 열어 B를 체크 해제하고 C를 새로 체크한 뒤 "투표 변경" 버튼을 클릭한다
- **Then** 선택 화면에는 A, C가 체크된 상태로 반영되고, 득표수에서 B가 1 감소하고 C가 1 증가한다 (A는 그대로)

성공 기준:
- [ ] 같은 기기로 같은 투표 링크 재접속 → 직전에 제출했던 선택(A, B)이 미리 체크된 채로 보인다
- [ ] 선택을 A, C로 바꿔 재제출 → B 득표수 -1, C 득표수 +1, A 득표수는 변화 없음
- [ ] 이 기기의 최종 반영 결과는 항상 가장 최근에 제출한 선택 하나뿐이다 (이전 제출은 남지 않는다)

### 5. 제한시간 경과 후 접근
- **Given** 투표의 제한시간이 지났다
- **When** 참석자(또는 주최자)가 그 투표 링크로 접속한다
- **Then** 투표 UI 없이 "투표가 마감되었어요" 안내와 함께 후보별 최종 득표수만 표시된다

성공 기준:
- [ ] 제한시간 경과 후 링크 접속 → 후보 선택 체크박스나 "투표하기" 버튼이 보이지 않고, 최종 득표수가 표시된다
- [ ] 마감 후에는 아직 투표하지 않은 기기로 접속해도 투표할 수 없다
- [ ] 마감 전 이미 투표를 제출했던 기기로 접속해도, 그 선택을 더는 바꿀 수 없다

### 6. 진행 중인 투표 목록 확인
- **Given** 주최자가 투표를 2개(하나는 진행 중, 하나는 마감됨) 만들었다
- **When** 추천 결과 화면의 "진행 중인 투표" 목록을 연다
- **Then** 두 투표가 모두 보이며, 각각 진행 중/마감 상태가 구분되어 표시된다

성공 기준:
- [ ] 진행 중 투표와 마감된 투표가 함께 목록에 나타나고, 상태 표시(예: "진행 중" / "마감")로 구분된다

## 불변 규칙

- 제한시간이 지난 투표는 어떤 경로로 접근해도 더 이상 투표를 받지 않는다 (시나리오 5에서 새 기기로 접속해도 동일).
- 화면에 표시되는 득표수는 실제 제출된 투표 수와 항상 일치한다.
- 같은 기기에서의 선택은 한 투표당 항상 "가장 최근 제출"만 반영된다 — 몇 번을 바꿔 제출하든 이전 선택은 득표수에 남지 않는다 (시나리오 4).
