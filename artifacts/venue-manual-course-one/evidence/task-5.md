# Task 5 검증 증거

스크린샷 도구(Browser MCP computer.screenshot)가 이 세션에서 pane 렌더링 문제로 사용 불가능해
DOM 텍스트 캡처로 대체한다 (`get_page_text` — 실제 dev 서버, `GENERATE_FIXTURE=1`, 실제 브라우저 렌더링).

## 흐름

1. 홈 화면 → "1차 장소 직접 입력" 탭 클릭 → 1차 장소명="브리비트 강남역점", 인원수=8, 예산=30000 입력 → 추천받기
2. `/results?place=브리비트+강남역점&people=8&budget=30000`로 이동, 캐시된 job이 있어 "이전에 검색한 결과가 있어요" 다이얼로그 표시 → "기존 결과 보기" 클릭
3. 결과 화면 렌더링 확인 (아래)

- 그룹 제목이 "브리비트 강남역점"(입력한 1차 장소명)으로 표시됨 — Scenario 2
